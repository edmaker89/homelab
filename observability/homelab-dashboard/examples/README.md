# Exemplos de desenvolvimento

`data/` é a demonstração principal. `scenarios/` contém máquinas fictícias para teste; não representa hosts existentes.

Os arquivos são sintéticos, baseados nos valores aproximados do brief. Datas fixas preservam o comportamento de freshness. O status de `fixture-partial` é propositalmente incompleto. As demais fixtures de inventory/status/guests são válidas contra os schemas do repositório.

Consulte o [README do dashboard](../README.md) para caminhos de execução e as convenções dos objetos livres de status. Não coloque telemetria real nesta pasta.
